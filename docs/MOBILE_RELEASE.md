# Android와 iPhone 출시 준비

게임 규칙과 화면은 같은 Godot 프로젝트에서 개발합니다. 두 플랫폼 모두 실제 기기 테스트와 각각의 앱 서명이 필요합니다. 아직 스토어에 제출할 상태는 아닙니다.

## 지금 검증된 것

- Godot 4.6.3에서 프로젝트 시작 및 게임 규칙 테스트 통과
- 인접 칸 터치와 재시작 입력 테스트 통과
- 세로 화면 설정과 모바일용 Compatibility 렌더러 설정

이 검증은 클라우드의 Linux 환경에서 수행했습니다. 실제 Android/iPhone 화면, 성능, 설치 파일은 아직 확인하지 않았습니다.

## Android 단계

1. Godot 버전에 맞는 공식 내보내기 템플릿과 Android SDK, JDK를 준비합니다.
2. 개발 중에는 서명된 디버그 APK를 만들어 Android 휴대폰에서 터치와 화면 크기를 확인합니다.
3. 출시 직전 앱 식별자, 아이콘, 권한을 확정하고 출시용 서명 키를 안전한 곳에 보관합니다.
4. AAB를 만들어 내부 테스트를 거친 다음 Google Play 심사를 신청합니다.

현재 클라우드에는 Android SDK와 Godot 내보내기 템플릿이 확인되지 않아 APK/AAB 생성은 검증하지 않았습니다.

## iPhone 단계

1. macOS 컴퓨터에서 Xcode와 같은 버전의 Godot 내보내기 템플릿을 준비합니다. iOS 앱의 빌드와 서명에는 Mac이 필요합니다.
2. 앱 식별자와 Apple 개발자 계정을 준비하고, iPhone 기기에서 화면과 터치를 확인합니다.
3. TestFlight 비공개 테스트를 거친 뒤 App Store 심사를 신청합니다.

현재 클라우드는 Linux라 iOS 빌드와 기기 검증을 할 수 없습니다.

서명 키, 인증서, 계정 비밀번호는 Git 저장소에 넣지 않습니다. Android와 iPhone 모두 게임 내용이 안정된 뒤 스토어 계정과 출시 서명을 준비해도 됩니다.
