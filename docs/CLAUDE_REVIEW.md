# Claude 협업 검토 · 2026-10-11

## 확인된 문제와 수정

- 3단계에 진입하면 첫 프레임에 월급이 청구되어, 동전이 없는 직원이 즉시 태업했다. 월급은 진입 60초 뒤부터 청구하고 남은 시간을 저장한다. 모바일 390×844에서 즉시 태업 없음, 60초 경계 청구, 지급 후 태업 해제, 저장 후 시간 복원을 확인했다.
- 이전 저장의 업그레이드 결제액은 칸 순서 배열이었다. 4개 칸이 전설 장비 칸 앞에 추가되어 옛 저장의 결제액이 엉뚱한 칸에 붙었다. 새 저장은 칸 이름을 키로 사용하고 기존 28칸 배열을 읽을 때 이동된 칸을 보정한다.

## 재미·경제 검토

- 은행 잔고 10,000에서 현재 이자는 분당 최대 200. 모든 직원을 고용해도 최대 16명 × 월급 8 = 128이므로 이자만으로 월급을 내고 72가 남는다. 직원 운영의 선택이 없어지고 잔고가 저절로 증가한다.
- 현재 목표 19개는 `오두막 3채 짓기`에서 끝난다. 3단계 큰 화로, 피자, 대장장이, 창고, 방어에 목표가 없다. 3단계 해금 뒤 무엇을 할지 안내할 필요가 있다.
- 30분 자동 플레이 기록은 이전 버전의 경로 단순화 검사다. 현 버전의 실제 플레이 지속 시간과 재미를 증명하지 않는다. 사람 5명의 첫 판매, 첫 업그레이드, 2·3단계 도달, 월급 부족, 마지막 목표 뒤 이탈 시점을 기록한 뒤 수치를 확정한다.
