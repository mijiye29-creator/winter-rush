# Codex와 Claude 함께 작업하기

두 AI 모두 같은 Git 저장소의 코드를 기준으로 작업합니다. 서로의 채팅 내용과 로컬 커밋은 자동으로 공유되지 않으므로, 작업을 넘길 때 **공유된 브랜치·커밋·남은 일**을 함께 알려 주세요. 다른 컴퓨터에서 작업한다면 먼저 브랜치를 GitHub에 올려야 합니다.

## 한 기능씩 진행

1. 이번에 만들 기능을 한 문장으로 정합니다. 예: “마을 확장 시 건물이 하나씩 보이게 하기”.
2. 한 AI가 별도 Git 브랜치에서 기능을 수정하고 `./tools/check.sh`로 검사한 뒤 커밋합니다. 다른 환경의 AI에게 넘길 때는 브랜치도 GitHub에 올립니다.
3. 다른 AI가 그 브랜치의 커밋을 읽고 오류, 조작감, 테스트 누락을 검토합니다. 고칠 내용은 같은 브랜치에 작은 커밋으로 추가합니다.
4. 기능을 직접 플레이한 다음 안정되면 `main`에 합칩니다.

같은 파일을 두 AI가 동시에 고치면 한쪽 수정이 사라질 수 있습니다. 작업을 바꿔 맡을 때는 먼저 앞선 수정이 Git에 저장됐는지 확인합니다. 앱 서명 키와 계정 정보는 AI 채팅이나 Git에 붙여 넣지 않습니다.

## Claude에게 전달할 문장

아래 문장을 Claude에 붙여 넣고 괄호 부분만 바꿔도 됩니다.

> `winter-rush` Godot 프로젝트의 `README.md`, `CLAUDE.md`, `docs/ROADMAP.md`를 먼저 읽어 줘. 현재 브랜치와 마지막 커밋을 확인하고, **(원하는 기능)**을 작은 변경으로 구현해 줘. 게임 규칙은 `scripts/game_state.gd`, 화면은 `scripts/main.gd`에 두고, 필요할 때 실제 행동을 검사하는 테스트를 추가해 줘. `./tools/check.sh`를 실행한 결과와 바뀐 파일을 한국어로 쉽게 설명해 줘. 다른 작업자가 수정 중인 파일은 먼저 확인해 줘.

Codex에 다시 맡길 때는 Claude가 만든 브랜치나 커밋과 “완료한 일 / 아직 안 된 일”을 알려 주면 됩니다.
