# Codex와 Claude 함께 작업하기

두 AI의 채팅과 로컬 커밋은 자동으로 공유되지 않는다. 이슈, 브랜치, 커밋, PR을 GitHub에 올린 뒤 링크를 다음 AI 채팅에 전달한다. 라벨은 담당 표시용이다.

1. 작업마다 GitHub 이슈 하나를 만들고 목표와 완료 조건을 적는다.
2. 이슈 링크를 Claude 채팅에 전달한다. Claude는 `main` 기준 작업 브랜치에서 수정하고, 검사 후 푸시해 PR을 만든다.
3. PR 링크를 Codex 채팅에 전달한다. Codex는 코드와 실제 플레이를 검토하고, 필요한 수정과 검사 결과를 PR에 남긴다.
4. 모바일 플레이와 검사를 확인한 뒤 사람이 PR을 병합한다.
