## 2026-10-10 · 웹 시제품 장시간 가속 검사

- 브라우저 게임 루프를 30분씩 3회 진행했다. 자동 플레이는 채집·사냥·운반·구매를 선택하고 이동 시간을 거리로 계산했다. 충돌 회피와 판단은 사람보다 단순하며, 체감 재미나 실제 플레이 시간의 측정값은 아니다.
- 수정 전: 가죽과 털가죽 보관함이 가득 차면 들고 있는 가죽을 내려놓지 못해 판매와 구매가 멈췄다. 남는 가죽을 동전으로 교환하고, 털 장비 완성 후 남는 털가죽도 교환할 수 있게 수정했다.
- 수정 후: 세 번 모두 30분 동안 실행 오류가 없었다. 당시 14개 목표의 완료 시점은 약 17분, 18분, 29분이었다. 30분 이후에는 목표가 없고 동전이 계속 쌓였다. 초반 세 번째 업그레이드는 약 4~6분이었다.
- 이를 바탕으로 첫 목표를 `스테이크 3개 판매`로 앞당겼다. 당시 목표는 15개였고, 현재 v1.4.1 코드는 24개다. 현재 순서의 장시간 측정과 사람 플레이테스트가 필요하다.
- 새 목표 순서에서 30분씩 3회 다시 검사했다. 15개 목표 완료는 약 15분 45초, 15분 41초, 18분 58초였다. 세 번째 업그레이드는 약 4분 3초, 7분 29초, 6분 45초였다. 모두 30분까지 실행 오류가 없었다.
- 자동 플레이는 좌표 이동을 거리 기반 시간으로 대체한다. 충돌, 길 찾기, 실제 손가락 조작과 재미는 검증하지 않는다. 목표 완료 시간을 실제 사용자 소진 시간으로 해석하지 않는다.
- 목표 완료 후 남는 선택지는 자원 판매와 반복 눈보라뿐이다. 다음 콘텐츠는 새로운 구매 목록보다 장작을 난방·판매·방어에 배분하는 선택이 적합하다.
