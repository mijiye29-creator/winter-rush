# Winter Rush: 확장 우선 게임 설계

이 게임의 첫 번째 재미는 **자원을 모아 마을이 커지는 것을 보는 것**입니다. 두 번째 재미는 **커진 마을을 공격에서 지키는 것**입니다. 성장 타일과 레벨은 이 흐름을 돕는 보조 요소입니다.

## 현재 플레이 흐름

1. 나무와 광석을 모아 시장에서 팝니다.
2. 10원, 20원, 30원을 차례로 내고 집·작업장·망루를 세웁니다. 각 건물은 지도에 표시되고 마을 체력을 3 늘립니다.
3. 주기적으로 나타나는 적의 칸으로 이동해 공격을 막습니다. 적이 마을에 닿으면 체력이 1 줄어듭니다.
4. 세 번 확장하고 레벨 3에 도달하면 승리합니다.

현재 건물마다 고유 능력은 없습니다. 망루가 자동으로 공격하지도 않습니다. 먼저 **건설 결과가 눈에 보이는지**와 **첫 확장까지 걸리는 시간이 지루하지 않은지** 확인합니다.

## 다음 작은 목표

- 처음 플레이하는 사람이 설명 없이 자원 → 판매 → 첫 건설을 할 수 있는지 확인합니다.
- 첫 건설을 마쳤을 때 지도의 변화가 바로 눈에 띄는지 확인합니다.
- 첫 공격에서 무엇을 지켜야 하는지 알 수 있는지 확인합니다.
- 이 세 가지를 실제 플레이로 확인한 뒤, 방어 건물의 능력과 건물 선택지를 정합니다.

Codex와 Claude는 이 우선순위를 기준으로 작은 변경을 나눠 맡습니다. 화면이나 입력을 바꾸는 작업은 `scripts/main.gd`, 게임 규칙을 바꾸는 작업은 `scripts/game_state.gd`를 중심으로 하며 `./tools/check.sh`를 실행합니다.
