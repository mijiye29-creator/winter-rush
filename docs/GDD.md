# 윈터 러시: 게임 기획서 (v0.1)

> 한겨울 숲속 마을. 눈보라가 오기 전에 장작을 모으고, 곰을 사냥해 마을을 먹여 살린다.

## 1. 한 줄 요약
**하이퍼캐주얼 아케이드 아이들** 장르(Burger Please, My Mini Mart 계열)에 **눈보라(시간 압박)**와 **북극곰(사냥감이자 위협)**을 더한 모바일 게임.

## 2. 레퍼런스와 차별점
| | 레퍼런스(화이트아웃 서바이벌 광고) | 윈터 러시 |
|---|---|---|
| 코어 | 나무 → 모닥불 → 고기 굽기 → 판매 | 동일 |
| 곰 | 배경 장식 | **고기 공급원 + 전투 + 습격자** |
| 긴장감 | 없음(무한 성장) | **주기적 눈보라**: 불이 꺼지면 손님이 끊김 |
| 목표 | 업그레이드 | 업그레이드 + **눈보라를 버티면 보너스** |

## 3. 코어 루프
```
 [숲] 나무 베기 ──장작──▶ [모닥불 왼쪽 칸] ──연료──┐
                                                  ▼
 [정문 밖] 곰 사냥 ──고기──▶ [모닥불 오른쪽 칸] ──▶ [그릴] 스테이크
                                                  │
                     [카운터] ◀──운반────────────┘
                        │ 주민이 구매
                        ▼
                    [동전 더미] ──▶ [업그레이드 칸]
```
- 이동만으로 모든 행동이 일어난다(자동 벌목, 자동 공격, 칸 위에 서면 자동 투입).
- 플레이어는 등에 짐을 쌓아 나른다. 쌓인 높이가 곧 "열심히 일한 느낌"이다.

## 4. 핵심 시스템

### 4-1. 눈보라 (시간 압박)
| 단계 | 시간 | 효과 |
|---|---|---|
| 평온 | 70초 (첫 회 80초) | 정상 |
| 경고 | 8초 | 화면 상단 경고, 안개 시작 |
| 눈보라 | 25초 | 불 연소 **×2.5**, 이동속도 **−35%**, 시야 축소, 곰 습격 |

- 눈보라 동안 불이 한 번도 꺼지지 않으면 **보너스 동전**: `30 + 20 × 눈보라 횟수`
- 불이 꺼지면 **마을 온기**가 떨어진다. 온기 35 미만이면 새 손님이 오지 않고, 0이 되면 기다리던 손님이 떠난다.
- 설계 의도: 평소엔 돈을 벌고, 경고가 뜨면 "장작을 비축할까, 곰을 막을까"를 고민하게 만든다.

### 4-2. 북극곰 (사냥감 + 위협)
- **들판 곰**: 정문 밖에 3마리(눈보라마다 +1, 최대 6). 가까이 가면 쫓아오고, 할퀴면 체력 −1.
- 피격 후 0.8초 동안은 다른 적에게 연속 피해를 받지 않는다.
- 곰 옆에 서면 도끼로 자동 공격. 처치하면 **고기 3개** 드롭, 8초 뒤 다시 나타남.
- 체력이 0이 되면 기절: **등에 진 짐을 모두 잃고** 마을로 돌아간다. 욕심과 위험 사이의 선택.
- **습격 곰**(눈 빨간 곰): 눈보라가 시작되면 `1 + ⌊횟수/2⌋ − 정문레벨` 마리가 마을에 들어와 고기, 스테이크, 장작 순서로 훔쳐 먹는다. 눈보라가 끝나면 들판으로 돌아간다.
- 마을 안에서는 체력이 2.5초마다 1씩 회복된다.

## 4-3. 자동화와 확장 (v0.2)
| 시설 | 효과 |
|---|---|
| 🧑‍🍳 서빙 직원 | 그릴의 완성품을 카운터로 자동 운반(한 번에 6개) |
| 🏹 사냥꾼 | 정문 밖 곰을 활로 사냥(사거리 4.5, 0.6초마다 2 피해), 고기 6개를 모아 귀환. 체력 8(자동 회복), 쓰러지면 3초 기절 |
| 🛒 장작 수레 | 나무꾼 운반량 4 → 8 → 12 |
| 🎣 얼음 낚시터 | 마을 2단계 확장으로 해금. 낚시꾼이 잡은 생선 → 생선구이(🪙18 × 단계 배율)를 생선 가게에서 판매 |

- **굽기 단계**: 날것 → 익음(스테이크 2.5초, 생선 2초) → 35초 방치하면 탐(검게 변하고 사라짐)
- **보스 곰**: 눈보라 4회마다 등장(체력 30+, 공격력 2). 처치하면 고기 8개와 🪙300
- **목표 15단계**: 스테이크 3개 판매로 첫 보상을 앞당긴 뒤, 사냥·눈보라 버티기·시설 해금 등으로 진행. 15개 달성 후의 반복 목표는 다음 개발 과제
- **손맛**: 휘두르기 3단 모션(예비동작 → 타격 → 복귀), 히트스톱, 화면 흔들림, 진동, 피격 숫자, 치명타(15%, 2배), 파티클, 효과음
- **업그레이드 칸**: 관련 시설 옆에 배치(도끼는 숲 입구, 정문과 사냥꾼은 정문 옆, 서빙은 그릴 옆, 낚시터는 동쪽 입구). 처음엔 가방과 도끼만 보이고 조건을 채우면 하나씩 등장. 살 수 없으면 흐리게 표시. 레벨업 후에는 칸을 나갔다 와야 다음 결제
- **콤보와 강타**: 곰을 직접 탭해 1.6초 안에 연속으로 맞히면 콤보가 쌓이고, 4번째 직접 공격은 회전 강타. 반경 3.4 안의 모든 곰에게 도끼 공격력 ×3 피해와 넉백. 강타 준비가 되면 도끼가 주황색으로 빛남
- **직접 공격 구분**: 곰을 탭하면 추적 후 0.24초짜리 수동 타격을 1회 실행한다. 연타 입력은 최대 4회까지 대기하고, 1.6초 안에 이어 맞히면 콤보가 쌓인다. 수동 공격에만 치명타(15%, 2배)와 4타 광역 강타가 적용된다. 근처 곰을 자동 공격할 때는 0.75초 간격의 기본 타격만 사용한다. 곰과 늑대는 피격 시 잠깐 경직되고 몸을 뒤로 젖힌다.
- **늑대**: 첫 눈보라부터 2마리씩 무리로 등장(20초마다 충원, 2번의 눈보라마다 상한 +2, 최대 6). 체력 2, 빠르게 추격. 처치하면 고기 1개와 가죽 1장(곰은 가죽 1장, 보스는 3장)
- **사냥꾼**: 사냥한 곰·늑대의 고기와 가죽을 함께 들고 귀환. 고기는 고기 칸, 가죽은 가죽 공방에 넣음
- **가죽 공방 + 가죽 가게**: 첫 가죽을 얻으면 동쪽 울타리 쪽에 생김. 🧵 가죽 장인(🪙150/350)을 고용해야 가동되며, 가죽 1장 → 가죽 제품 1개(3초 → 1.6초)를 가게 진열대에 바로 올림. 손님은 울타리 밖에서 가죽 제품(🪙25)을 사감. 보관함이 가득 차면 추가 가죽은 🪙4에 교환
- **얼음 낚시터 확장**: 낚시터(🪙400)를 사면 마을이 동쪽으로 넓어지고 생선 가게가 생김. 생선은 굽지 않고 생선 가게에서 바로 판매(🪙12). 🪝 낚시꾼(🪙250/500)이 얼음 구멍에서 낚아 가게를 채움
- **판매 점원**(🪙200/450): 모든 가게에서 동시에 받는 손님 1 → 2 → 3명
- **늑대 펫**: 늑대를 잡으면 15% 확률로 새끼 늑대가 나옴(최대 1마리). 고기를 들고 다가가면 길들임. 처음엔 작고 약하며(공격력 1), 공격 횟수 15/40/80/140회마다 레벨업해 몸이 커지고 강해짐(최대 Lv5, 공격력 6). 가방 +4
- **업그레이드는 동전으로만**: 털 장비(털모자·털장갑·털외투)와 털가죽 결제는 제거
- **자동 저장**: 4초마다 localStorage에 저장. 가방, 위치, 체력, 날씨 단계와 남은 시간, 습격 곰도 이어하기에서 복원

## 단계 구조 (v0.4)
- **1단계 (작은 마을)**: 나무 + 곰고기 → 스테이크 판매. 나무꾼·서빙 직원·사냥꾼·판매 점원으로 기본 운영을 만든다. 가죽은 나오지 않는다
- **2단계 (낚시터 🪙400, 스테이크 25개 판매 후 등장)**: "뿅!" 하고 울타리가 동쪽 x=16까지 넓어지고 랜턴이 생기며, 모닥불이 마을 가운데(x+3)로 옮겨져 돌기둥 불꽃 장식이 붙는다
  - 북쪽 울타리에 **훈제 생선 가게**: 생선 → 훈제장(장작 1개 = 생선 2마리, 2.2초) → 훈제 생선 🪙18. 손님 줄은 오른쪽(+x)으로, 고기 가게 줄은 왼쪽(−x)으로 서서 겹치지 않음
  - 사냥꾼 숙련 Lv3(2단계에서만 구매 가능)부터 고기와 가죽을 함께 수집 → 동쪽에 가죽 공방 + 가죽 가게 개방
- **직원은 한 명씩, 숙련도로 성장**: 나무꾼(운반 4/8/12, 속도↑), 서빙(6/10/14개, 속도↑), 사냥꾼(공격력 2/3/4, 공격 간격↓), 판매 점원(동시 손님 1→2→2→3, 판매 간격 .35→.14초), 낚시꾼(6/10마리, 2.2→1.4초)
- **장작 소모 증가**: 모닥불 연소 속도가 눈보라를 버틸 때마다 +15%(최대 ×2.2), 2단계 훈제장이 장작을 추가로 소모
- 최대 레벨 업그레이드 칸은 사라진다

## v0.5 변경
- **업그레이드 칸 의도 구분**: 칸 위에서 멈춰 0.5초 서 있어야 결제 시작. 지나가기만 하면 돈이 빠지지 않음(`T.padDwell`)
- **생선 화덕**: 생선 가게 옆에 붙은 화덕. 화덕 전용 장작 칸과 생선 칸에 직접 넣어야 함(모닥불 장작을 자동으로 가져가지 않음). 구운 생선은 화덕 앞 선반에 쌓이고, 플레이어나 쉐프가 가게 진열대로 옮겨야 팔림
- **생선 상자**: 낚시꾼은 연못 옆 생선 상자에 생선을 쌓고, 쉐프(서빙 직원)가 상자 → 화덕, 화덕 → 가게로 나름. 쉐프는 스테이크·생선 중 밀린 일을 골라 처리
- **나무꾼**: 2단계에서 화덕 장작이 부족하면 화덕 장작 칸으로도 배달
- **생선 점원**: 생선 가게 전용 점원을 따로 고용(🪙200/400/700)
- **가죽 장인**: 모닥불 장작 더미에서 통나무를 가져와 공방 옆에 작은 불을 피움. 장작 1개로 가죽 2장 가공

## v0.6 변경

- **은행 삭제**: 은행 칸·건물·점원 입금·이자 삭제. 모닥불 Lv14는 🗿 명성 동상만 열림. 3단계부터 60초마다 월급(직원 1명당 🪙8 × 단계 판매 배율)은 주머니에서 나가고, 모자라면 태업(속도 절반)
- **가방**: 가방 칸 삭제. 🦸 주인공 칸 레벨마다 가방이 커짐(10/16/22/28/34/40/46/52/60칸, 늑대 펫 +4). 전설 장비(검치호 갑옷·매머드 뿔 창)는 대장간에서 전리품으로 만드는 별도 칸으로 유지
- **퀘스트**: 목표 줄이 📜 퀘스트가 되고 보상을 미리 보여줌(`🎁 🪙60 🍖 스테이크 4개`). 완료하면 보상 카드가 뜨고 동전 비가 내림. 보상은 🪙 + 선물 하나: 🍖 스테이크(진열대), 🪵 장작(모닥불), 🎉 마을 잔치 N초(판매가 ×1.3), 🐯 가죽·🦣 뿔(대장간 재료). 동전 보상은 이전보다 약 1.3~1.5배
- WASD: 키 입력을 `e.code`로 읽어 한글 입력 상태에서도 이동(이전엔 ㅈ/ㅁ/ㄴ/ㅇ로 들어와 무시됨). 창을 벗어나면 키 상태 초기화
