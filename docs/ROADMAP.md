# 출시까지의 순서

## 1. 재미 확인 — 현재 진행 중

- [x] 이동, 채집, 판매, 확장, 레벨업, 마을 방어가 되는 시제품
- [x] 확장할 때 집, 작업장, 망루가 지도에 나타나도록 표시
- [x] 게임 규칙 자동 검사
- [ ] 건물 확장이 첫 번째 재미가 되도록 비용과 소요 턴 조정
- [ ] 방어를 확장한 마을과 연결하는 선택지 설계
- [ ] 실제 휴대폰 크기에서 조작과 글자 크기 확인
- [ ] 플레이해 보고 너무 어렵거나 쉬운 수치 조정

## 2. 게임 완성

- [ ] 겨울 숲과 마을 그림, 움직임, 효과음
- [ ] 시작 화면, 설명 화면, 일시정지
- [ ] 저장/이어하기와 오류 상황 처리
- [ ] 새로운 자원, 건물, 적 등 콘텐츠 추가
- [ ] 저작권과 사용 허가가 명확한 소재만 사용

## 3. Android와 iPhone 출시 준비

- [x] 출시 대상 결정: Android와 iPhone 모두
- [ ] Android SDK와 Godot 내보내기 템플릿 준비
- [ ] Mac에서 Xcode와 Godot iOS 내보내기 환경 준비
- [ ] 실제 기기에서 성능·화면·터치 테스트
- [ ] 앱 이름, 아이콘, 스크린샷, 소개문 작성
- [ ] 스토어 개발자 계정과 정책 확인
- [ ] 서명된 출시 빌드 제작 후 비공개 테스트
- [ ] 문제 수정 후 스토어 심사 제출

각 단계는 작은 기능 → 플레이 → 수정 → Git 커밋 순서로 진행합니다. 유튜브 영상은 아이디어 참고용이며, 화면·소리·코드는 직접 만들거나 사용 허가를 확인합니다.

플랫폼별 필요한 도구와 확인 순서는 [모바일 출시 안내](MOBILE_RELEASE.md)를 참고합니다.
